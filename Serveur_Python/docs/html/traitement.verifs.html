traitement.verifs module¶

Module : verifs.py

Description :

Ce module permet de vérifier les informations d’un billet d’embarquement transmises par un client, de contrôler les autorisations de l’agent et de générer une réponse adaptée au résultat des vérifications.

Auteur : Alexandre BURIN, Menaouer AMMARI, Hugo DELHELLE Version : 1.0

traitement.verifs.creer_reponse(agent: dict, billet: dict, demande: dict) → dict¶

Génère la réponse correspondant aux résultats des vérifications.

La fonction vérifie successivement l’existence du billet, les autorisations de l’agent, la porte d’embarquement et le numéro de vol.

Parameters:

  • agent – Informations de l’agent récupérées en base

  • billet – Informations du billet récupérées en base

  • demande – Données transmises par le client

Returns:

Réponse contenant le statut et le message de contrôle. En cas de contrôles conformes, elle contient également le nom du passager et son numéro de siège

traitement.verifs.verifier_billet(demande: dict) → dict¶

Vérifie un billet d’embarquement à partir d’une demande client.

La fonction valide le format et les données de la demande, récupère les informations du billet et de l’agent dans la base de données, puis génère une réponse selon le résultat des contrôles.

Parameters:

demande – Données transmises par le client

Returns:

Réponse contenant le statut et le message de vérification, ainsi que les informations du passager si les contrôles sont conformes

Raises:

ValueError – Si la demande ou ses données sont incorrectes

traitement.verifs.verifier_identifiants(demande: dict) → None¶

Vérifie la validité des identifiants présents dans la demande.

Chaque identifiant doit être un entier strictement positif. Les valeurs booléennes sont également rejetées.

Parameters:

demande – Dictionnaire contenant les données de la demande

Returns:

None si les identifiants sont conformes

Raises:

ValueError – Si un identifiant est absent ou incorrect

traitement.verifs.verifier_porte_et_num_vol(demande: dict) → None¶

Vérifie la conformité de la porte d’embarquement et du numéro de vol.

Chaque champ doit contenir une chaîne de caractères ASCII alphanumérique dont la longueur respecte la limite configurée.

Parameters:

demande – Dictionnaire contenant les données de la demande

Returns:

None si les champs sont conformes

Raises:

ValueError – si un champ est absent ou incorrect
