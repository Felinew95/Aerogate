main.serveur module¶

Module : serveur.py

Description :

Ce module assure le fonctionnement du serveur Aérogate.

Il permet d’établir des connexions avec les clients, de recevoir leurs demandes au format JSON, de vérifier les informations des billets auprès de la base de données et de leur transmettre une réponse.

Les événements importants sont enregistrés dans un journal. Celui-ci utilise un fichier avec rotation automatique et bascule vers la console en cas d’erreur d’accès au fichier.

Auteur : Alexandre BURIN, Menaouer AMMARI, Hugo DELHELLE Version : 1.0

main.serveur.init_journal(nom_log: str = 'Aérogate', fichier_log: str = 'aerogate.log') → Logger¶

Initialise le journal du serveur.

Configure le logger du serveur avec le niveau INFO et désactive la propagation des messages vers les loggers parents.

Les messages sont enregistrés dans un fichier avec rotation automatique. Si le fichier ne peut pas être créé ou ouvert, les messages sont redirigés vers la console.

Returns:

Logger configuré pour le serveur.

main.serveur.lancer_serveur() → None¶

Lance le serveur Aérogate.

Initialise le socket serveur, attend les connexions des clients et traite leurs demandes successivement.

Chaque demande est reçue au format JSON, vérifiée puis transmise à la fonction de contrôle des billets. Une réponse JSON est ensuite envoyée au client.

Les événements de connexion, les demandes et les résultats sont enregistrés dans le journal.

main.serveur.lecture_demande(adresse_ip_client: str, connexion: socket, journal: Logger) → dict¶

Lit et vérifie la demande envoyée par un client.

Récupère le message transmis par le client, vérifie sa longueur et son format JSON, puis retourne les données sous forme de dictionnaire.

Les informations relatives à la demande sont enregistrées dans le journal, sans exposer les données personnelles du passager.

Parameters:

  • adresse_ip_client – Adresse IP du client connecté.

  • connexion – Socket associé à la connexion du client.

  • journal – Logger utilisé pour enregistrer les événements.

Returns:

Dictionnaire contenant les données de la demande.
