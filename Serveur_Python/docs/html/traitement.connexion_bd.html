traitement.connexion_bd module¶

Module : connexion_bd.py

Description :

Ce module permet de gérer la connexion à une base de données PostgreSQL. Il charge les paramètres de connexion depuis un fichier .env et fournit les fonctions nécessaires à l’ouverture, à l’interrogation et à la fermeture de la connexion.

Auteur : Alexandre BURIN, Menaouer AMMARI, Hugo DELHELLE Version : 1.0

None.
